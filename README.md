# SweScribe ASR

## What is SweScribe?

SweScribe is an AI transcription tool built around [Pianissimo](https://klang.ai/sv/pianissimo/) by [klang](https://klang.ai/), an open model based on **NVIDIA Parakeet v3** with fine tuning for the Swedish language. More information and specifications can be found on the Pianissimo site or on [huggingface](https://huggingface.co/KlangAI/pianissimo-sv).

## Features

* The tool currently comes with an easy to use UI
* Features two models, one using NeMo Toolkit for more accurate transcriptions, and one using ONNX which is lighter but not as accurate
* Features real time transcription, but audio files are also supported
* The transcriptions can be saved as .txt files
* Everything runs locally, no information or data is collected from the transcriptions

## Why was SweScribe created?
SweScribe was created as a school project for [Ung Företagsamhet](https://ungforetagsamhet.se/)
